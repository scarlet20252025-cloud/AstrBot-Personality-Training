# AstrBot 大肥鱼 · 人格训练库

QQ 群聊机器人「大肥鱼」的人格、测试、诊断与运维资料集中在这里。

**目标**：让她在群里说话像一个真人，不啰嗦、不复述、听得懂梗、会打趣、理解得了上下文。

---

## 这个库解决什么

调一个群聊机器人的人格，坑不在「写不出好 prompt」，而在于：

1. **你写的东西会被逐字照抄。** 人格里每一条「对方：X / 我：Y」的示例，模型都当台词库用。实测 8 组全部 100% 逐字复现。
2. **改了没效果，多半不是 prompt 的问题。** 有 4 个地方会盖住人格：插件注入、时间戳错序、`tools: []` 关掉所有工具、模型被中转站偷偷换掉。
3. **「感觉」不能当判据。** 「有点啰嗦」「不够机灵」这类反馈必须量化成可测指标，否则每轮都在原地打转。

这个库记录了每一个坑的**实测证据**和**修法**，避免重踩。

## 三条最重要的结论

### 1. 示例会被照抄，所以要给「策略」不给「台词」

```
❌ 错误写法（会被逐字复现）
  对方：我考砸了
  我：过来 抱一下 考砸一次能说明啥 你又不是只考这一次

✅ 正确写法（现场生成）
  对方说考砸了、很沮丧——我把声音放低，先让他说。不急着分析，不给建议。
```

实测：删掉全部成品句后，**照抄率从 88% 降到 0%**。

### 2. 命名口癖是最强的重复触发器

人格里写「我有几个顺口词，比如『呀』『嘛』『诶』」——**只出现一次**，输出里「诶」开头占比就有 41%。

原因是模型对「被点名」的敏感度远高于词的词频。同理，写「不要自嘲」并附上 11 个 ❌ 负例，等于给它 11 个坏样本。

**做法**：不列举具体词，只用正面描述 + 结构多样的正例。

### 3. 复述对方用词 = 最偷懒的接话

用户反馈「她喜欢附属（复述）别人的话」，实测 **首句搬用对方 2-gram 的比例 61%**。

根因是我自己在人格里写的：

> 具体的东西是指他提到的那个物件、那个数字、那个动作

模型理解成「把那几个字搬到句首」。改成「接的是那件事的**意思**，不是那几个字」后，**降到 33%**。

## 怎么用

### 改人格

1. 编辑 `persona/persona-v28.md`（或新建 v29）
2. 用 `tools/ab-persona.py` 做 A/B，别凭感觉
3. 在 `persona/CHANGELOG.md` 记下改动 + 数据

### 新增知识（梗、黑话）

抽象词走知识库，不走人格。人格只留「遇到不懂的词先查」这条规则。

```bash
python tools/add-kb-entries.py --kb 网络流行语释义库 --file data/slang-samples.txt
```

### 排查「改了没效果」

按顺序查这四层：

```
1. tools 是不是 [] ？        → diag-tools.py
2. 有没有插件在注入？        → diag-inject.py
3. 时间戳对不对？            → 见 docs/01
4. 模型是不是被换了？        → 看 agent_runner.config.model.provider_id
```

第 4 条最容易忽略：**中转站会偷偷把模型换成别的**。实测某站名义上是 deepseek，实际输出「我默认把结论和依据分开写」这种通用助手腔，查配置才能发现。
