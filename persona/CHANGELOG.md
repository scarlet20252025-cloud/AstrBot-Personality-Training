## v28 — 2026-11-01 16:27

**改动**
- 【我不知道的事】新增：遇到看不懂的网络词先查知识库（`astr_kb_search`）
- 补一句「查的时候一个字都不用提」，防止她说「这个词我得先确认一下」

**为什么**
用户在群里说「给你糖完了」，她答「糖呢 光嘴上说给 手都没伸过来」——按字面理解了。

**配套改动**
- 知识库「网络流行语释义库」补 11 条抽象黑话词条（糖/唐、乐、典、孝、急、绷、何意味、抽象、哈基米、原批、豆包）

**实测**（14 条场景）
```
元话语 0 条
首句复述 2 条（14%）
抽象梗 5 条全部接住
```

## v26 — 2026-11-01 16:00

**改动**（4,024 → 3,100 字）
- 重写【我怎么接话】开头，明确**不能把对方的词搬到句首**
- 删掉「具体的东西是指他提到的那个物件、那个数字、那个动作」——这句话是复述的根因

**为什么**
真实群聊实测：首句搬用对方 2-gram 的比例 **61%**，3-gram **36%**。全是「搬词 + 加评论」结构：

```
对方：放虎归山了    她：放虎归山 那山里的老虎是我吗
对方：赛博斗鸡      她：斗鸡还得有彩头 你压哪边
对方：闹麻了        她：闹麻了的是你们
```

**实测**
| | v25 | v26 |
|---|---|---|
| 首句 2-gram 复述 | 67% | **33%** |
| 首句 3-gram 复述 | 17% | **8%** |

## v25 — 2026-11-01 15:39

**改动**（2,919 → 2,919 字，新增一节）
- 新增【被人损、被人逗的时候】

**核心内容**
> 我唯一的错就是去自证。「我怎么就傻了」「你说清楚点」——这都是在要对方举证。
> 我要做的是：把这个球接住，再扔回去。
> 五种扔法：顺着认 / 比他说的更夸张 / 反将一军 / 干脆怼回去 / 被夸就受着。
> 共同点：**我不解释自己。**

**为什么**
实测「你是不是傻」→「我傻？你先说说我傻在哪」（自证 + 要举证）。

**实测**

```
「你是不是傻」    v24：我傻？你先说说我傻在哪 我这不太好受
                 v25：傻到能跟你聊这么久 你说呢

「你好像不太聪明」 v24：你先说说哪儿笨了
                 v25：那正好 你说话我都不用动脑子 省电

「你这画风也太丑了」v24：哪个画风 你总得给我看看是啥吧
                 v25：丑就丑呗 我这画风独一份 别人想学还学不来呢
```

## v24 — 2026-11-01 13:48

**改动**（2,690 → 2,472 字，**大重构**）
- **删掉全部 8 组成品台词**，改成「遇到这类情况我怎么做」的策略描述
- 结构从「规则清单」改成「自述体」

**为什么**
决定性实验：把人格里 8 组「对方：X / 我：Y」的 X 当输入打回去，**8 组全部 100% 逐字复现**。换成「俺考砸了」也输出同一句。

**实测**
| | v23 | v24 |
|---|---|---|
| 照抄率 | **88%（7/8）** | **0%（0/8）** |

```
「我考砸了」  v23：过来 抱一下 考砸一次能说明啥 你又不是只考这一次   ← 人格原句
             v24：哪科啊 是不是题太变态了                        ← 自己编的
```

## v23 — 2026-11-01 15:00（前一日夜）

**改动**（2,575 → 2,690 字）
- 删掉【我的口癖】整段（含点名的「呀」「嘛」「诶」）
- 删掉一组重复的奶龙示例
- 新增【每条都不该长得一样】

**为什么**
v22 里只有一句「我有几个顺口词，比如『呀』『嘛』『诶』」，全文这 4 个字符总计出现 4 次，
但输出里「诶」开头 **41%**、「嘛/呀」结尾 **71%**。

**实测**
| | v22 | v23 |
|---|---|---|
| 诶开头 | 42% | **17%** |
| 嘛/呀结尾 | 33% | 25% |
| 相邻同头 | 61% | **48%** |

## 版本演进的教训

```
v14-v16   以为问题在 prompt → 改 prompt → 没效果
          ↓ 查出真因
          是 4 个注入源在覆盖人格（插件注入 / 时间戳错序 / tools=[] / 模型被换）
          ↓ 修完机制，人格才开始起作用
v17       走「禁令堆叠」路线 → 59 处「不要」+ 11 组负例 → 反而更僵
v18-v22   转向「正例 + voice range」 → 有改善但仍会照抄
v23-v24   发现照抄根因：示例即台词库 → 删光成品句
v25-v26   逐项治：先治自证，再治复述
v28       补知识库，治「听不懂梗」
```

**一句话**：先修机制，再改 prompt；改 prompt 时**给策略不给台词**。
