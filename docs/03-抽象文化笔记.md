# 抽象文化笔记

给群聊机器人补「听得懂梗」的能力时收集的资料。结论先行：**抽象黑话不能按字面理解，且大部分不该写进人格，该进知识库。**

---

## 一、什么是抽象文化

原为哲学术语。网络语境下指**难以常规理解的言行**：

- 作动词 = 做怪异举止
- 作形容词 = 另类、离谱、没道理

核心特征：反逻辑、反严肃、反常规。功能上偏中性——情绪纾解、群体共鸣、娱乐。

**源流**：2015 年前后直播团体「抽象工作室」（李赣、孙笑川），粉丝以审丑、看其出丑为乐 → 衍生「乐子人」。扩散到贴吧（孙吧）、B 站鬼畜、虚拟主播圈。

**无害化**：2024 年「抽象」成为小红书年度关键词，官方定义「用无厘头来调剂日常，用插科打诨戏谑人生」。《语言文字周报》十大流行语收录「搞抽象」，两种具体方式：废话文学、抖机灵。

到 2026 年，它已经是大众社交货币，不再是圈层黑话。

---

## 二、核心弹药：单字回复

单字回复是抽象调侃的最小单位，一个字的杀伤力比一段话强。

| 字 | 意思 | 什么时候用 |
|---|---|---|
| **典** | 「这话太经典了」 | 对方说的话在你意料之中，带讽刺 |
| **孝** | 「某势力的大孝子」 | 对方过度维护某个跟自己无关的东西 |
| **急** | 「他急了」 | 对方情绪上头 |
| **乐** | 「笑死我了」 | 觉得对方的话离谱好笑 |
| **绷/蚌** | 「绷不住笑了」 | 对方言论违背常识 |
| **赢** | 反讽式精神胜利 | 自嘲或讽刺 |

⚠ **判定：这一整套是骂战/拒绝交流的工具，攻击性很强。**

给聊天机器人用会变成杠精。**只学不装**——取「乐」「绷不住」的幽默面就够了。

## 三、必须知道的几个词（已入知识库）

这些都是**不能按字面理解**的：

| 词 | 真实含义 |
|---|---|
| **糖/唐/唐完了** | 源自「唐氏综合征」的谐音，说人言行离谱、脑回路清奇。「给你糖完了」= 你这波操作太离谱了。**不是给糖吃。** |
| **豆包** | 字节跳动的 AI 助手。说「你个豆包」= 说你是个 AI、说你笨。**不是吃的豆包。** |
| **原批** | 「原神玩家」的贬称，带攻击性 |
| **何意味/hyw** | 伪日语写法，意思就是「什么意思」 |
| **哈基米** | 对可爱小动物的嗲称 |
| **抽象** | 离谱、难以理解。**不是「不具体」。** |

**实测证据**：未补词条前，知识库搜「唐」只命中「唐僧」「唐朝」，一条黑话都没有。所以她真的不理解，不是装傻。

## 四、调侃的核心机制：把球扔回去

这是整份笔记里最有操作价值的一条。

**对方调侃你 = 扔了一个球给你。**

```
板着脸说「你干吗笑我」        → 球掉地上
跟着哈哈笑                    → 接住了，但没扔回去，还是无趣
接住 + 扔回去                 → 对了
```

**万能招式**：「其实比你想的更严重」

```
「你数学真差」  → 「我数学是差，可我物理更差呀」
「你唱歌难听」  → 「这还叫难听？我可以唱得更难听！」
```

**其他招式**：
- 自我贬抑 + 反杀：「你长得丑」→「但我想得美啊」
- 逆向反转：「我不相信星座，因为人应该主宰自己的命运。水瓶座的人都这么想。」

**关键提醒**：**把一招练熟比学十招有用。** 拼的是反应速度，不是招式数量。

## 五、绝对不能进人格的部分

用户明确要求「不要往不讨喜的方向影响」。以下排除：

| 排除项 | 原因 |
|---|---|
| 典/孝/急/蚌/赢 全套 | 骂战工具，装上必变杠精 |
| 「鼠鼠」「下水道老鼠」 | 底层自贬黑话，人格降格 |
| 「米线」（底线谐音） | 攻击性语境 |
| 过时梗堆砌（YYDS/绝绝子/栓Q） | 已嫌土，用了显老 |
| 地域、疾病、性别相关 | 冒犯 |

## 六、落地结论

**三条分离**：

1. **词义 → 知识库。** 具体词的释义进「网络流行语释义库」，让她检索。人格里只留一句「遇到不懂的词先查」。
2. **机制 → 人格。** 「把球扔回去」「不自证」这类是行为策略，写进人格。
3. **攻击性用法 → 全部不装。** 只取幽默面。

实测效果（v28）：

```
你个豆包别掺和了，给你糖完了 → 我逗你两句也成掺和了？那我掺和定了
糖完了                      → 甜到齁是吧 谁这么会说话
典                          → 你这一句「典」够狠 我这还没开口呢就先被定性了
你是不是唐                  → 唐得我自己都想报个名 你说是哪种唐
```
