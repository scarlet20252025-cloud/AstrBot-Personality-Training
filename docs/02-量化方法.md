# 量化方法

「有点啰嗦」「不够机灵」「人机感重」——这些反馈没法直接用来改 prompt。
必须先把它们翻译成能算的数字，否则每一轮都在凭感觉调整。

---

## 一、复述率（Echo Rate）

**测什么**：她回复的第一个分句里，有多少字是原样搬用对方刚说的话。

**为什么这么测**：真实群聊里 61% 的回复首句都在重复对方用词，而人不会这么说话。这是「不机灵」最可量化的表现。

```python
def frags(s, n):          # 取所有 n-gram
    c = re.sub(r"[^\u4e00-\u9fffA-Za-z0-9]", "", s or "")
    return {c[i:i+n] for i in range(max(0, len(c)-n+1))}

first = re.split(r"[ 　,，。！？\n]", reply)[0]     # 第一个分句
echo  = len(frags(first, 3) & frags(user_msg, 3))  # 3-gram 重合数
```

**判读**：
- 2-gram 重合 → 一定在复述
- 3-gram 重合 → 明显复述
- 目标：3-gram 复述率 **< 10%**

**实测基线**：

| 版本 | 首句 2-gram 复述 | 3-gram 复述 |
|---|---|---|
| v25（真实群聊） | 61% | 36% |
| v26 | 33% | 8% |
| v28 | — | 14%（14 条小样本） |

## 二、句式模板化（Template Collapse）

**测什么**：连续回复的「形状」是否雷同。

三个指标：

```python
# 1. 两段式占比 —— 多少条回复正好是「两行」
two_para = sum(1 for r in replies if len(r.split("\n")) == 2) / len(replies)

# 2. 长度变异系数 —— 真人打字长短参差，模板则整齐
cv = stdev(lengths) / mean(lengths)

# 3. 相邻同头率 —— 连续两条用同样的开头
same_head = sum(1 for i in range(1, n) if head[i] == head[i-1]) / (n-1)
```

**判读**：
- 两段式 > 60% → 模板病
- CV < 0.5 → 长度太整齐，一眼假
- 相邻同头 > 40% → 开头坍缩

**实测**：

| 版本 | 两段式 | 长度CV | 相邻同头 |
|---|---|---|---|
| v22 | 85% | 0.31 | 61% |
| v23 | 25% | 0.59 | 48% |
| v28 | 正常 | ~0.6 | <20% |

## 三、元话语（Meta-talk）

**测什么**：她有没有说出「我在查」「我得确认一下」这种暴露自己是程序的话。

```python
META = re.compile(r"我得先确认|先确认一下|别乱接|我查一下|我查了|按字面|翻资料|"
                  r"作为一个\s*AI|有什么可以帮|希望对你有帮助")
```

**为什么重要**：真人不会先声明自己去查字典。

**实测**：v27 出现了「『唐』这个词现在网上的意思我得先确认一下」。
补规则「查的时候一个字都不用提」后 → **0/14**。

## 四、A/B 对照方法

**不要**「改完看一看感觉如何」，那不可证伪。

标准流程：

```
1. 准备两份人格文件（v_old.md / v_new.md）
2. 用同一组场景（≥12 条，覆盖不同压力类型）
3. 依次部署 → 跑同样的场景 → 记录
4. 算指标 → 对比 → 选优
5. 记录到 CHANGELOG
```

**关键**：
- 场景必须**取自真实群聊**，不要自己编。编的场景测不出真问题。
- 每条场景跑 2 次以上。单次采样的随机性足以让 3 vs 2 的差异毫无意义。
- 部署后要**回读校验**，确认真的写进去了。

## 五、解析 AstrBot 的 SSE 输出

**坑**：webchat 走流式，`plain` 事件是逐 token 的分片，`complete` 事件才是最终全文。

```python
# ❌ 错：把所有 plain 拼起来 → 每个字之间插入分隔符
for ev in events:
    if ev["type"] == "plain":
        text += ev["data"]

# ✅ 对：只取 complete
for ev in events:
    if ev["type"] == "complete":
        d = ev["data"]
        text = d if isinstance(d, str) else d.get("content", "")
```

第一版 A/B 就是因为这个错误，统计出了「字间全是 `/`」的假数据。

## 六、什么时候该怀疑不是 prompt 的问题

出现以下任一情况，**先查机制，不要改人格**：

| 症状 | 优先排查 |
|---|---|
| 工具全失效（联网/知识库/表情包） | `tools: []` |
| 接不上话、答非所问 | 时间戳错序 |
| 输出通用助手腔、带 Markdown | 模型被换 |
| 回复里有思考过程 | `reasoning_content` 泄漏 |
| 突然开始说固定句式 | `expression_patterns` 又累积了 |
| 测不出功能但代码没问题 | 测试通道走的是不同链路（流式） |

这六条覆盖了实际遇到过的 90% 的「改了没效果」。
